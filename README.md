# Verilog HDL & SystemVerilog – VLSI Projects

## 👋 About This Repository

Welcome to my VLSI Design and Verification repository! This repository contains my hands-on projects, coding exercises, and practical implementations using **Verilog HDL and SystemVerilog**. My goal is to strengthen my knowledge of Digital Logic Design, RTL Design, Functional Verification, and ASIC Design fundamentals.

I am an Electrical and Electronics Engineering graduate interested in building a career as a **VLSI RTL Design / Design Verification Engineer**.

## 🛠️ Technical Skills

- **HDL Languages:** Verilog HDL, SystemVerilog
- **Digital Design:** Combinational and Sequential Logic
- **RTL Design:** FSM (Mealy & Moore), Counters, Registers, ALU
- **Verification:** Testbench Development, Simulation, Debugging
- **Protocols:** UART, SPI, I2C, AMBA (AXI, APB basics)
- **Tools:** GVim, Icarus Verilog, GTKWave, EDA Playground
- **Operating System:** Ubuntu Linux
- **Version Control:** Git and GitHub
